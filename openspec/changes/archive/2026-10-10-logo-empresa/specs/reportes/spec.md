# Reportes Specification — Delta

## ADDED Requirements

### Requirement: Report Header Company Data
Every PDF report generated by the system SHALL show, in its header, the company **name**, **address** and **phone**, together with the company logo. This data SHALL be resolved from the branding cache (`EmpresaBranding`) and SHALL NOT be hardcoded. When the cache holds no configured data, the header SHALL fall back to the packaged defaults so PDFs always render a complete, valid header.

#### Scenario: Header shows configured company data
- **WHEN** a report PDF is generated after the company configuration has been saved
- **THEN** its header shows the configured company name, address and phone and the configured logo

#### Scenario: Header falls back to defaults
- **WHEN** a report PDF is generated and no company configuration has ever been saved
- **THEN** its header shows the packaged default company data and logo

#### Scenario: Shared header reused
- **WHEN** a report using the shared header (`ComposeEncabezadoTaller`) is generated
- **THEN** the header renders the same company name, address and phone as the configuration, without hardcoded literals
