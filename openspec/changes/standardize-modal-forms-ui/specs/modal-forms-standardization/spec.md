# Delta Spec: Modal Forms Standardization

## Modified Requirements

### Requirement: Frm Dialogs Visual Standardization
- All `Frm*.xaml` files MUST adopt:
  - Header Title Foreground: `#2C3E50`
  - Guardar Button: `Background="#27AE60"`, `Foreground="White"`, `FontWeight="Bold"`, `CornerRadius="6"`, `Width="95"`, `Height="34"`
  - Cancelar Button: `Background="#C0392B"`, `Foreground="White"`, `FontWeight="Bold"`, `CornerRadius="6"`, `Width="95"`, `Height="34"`
  - Inline Add Buttons (`btnAgregarMarca`, `btnAgregarModelo`, `btnAgregarRol`): `Background="#27AE60"`, `Foreground="White"`, `FontWeight="Bold"`, `CornerRadius="6"`, `Width="30"`, `Height="30"`, `Content="➕"` (icon only).
